## Specific candidate invariant / trace

If the World commits damage in step `k`, it matures in P2 of `k+1`, and Show records `beatDisposition=blocked` in P6 of `k+1`. Because `ordinaryCueDueStep >= k+2`, the Beat is already blocked before ordinary Cue evaluation.

At `ordinaryCueDueStep`, Show emits exactly one `SCHEDULED_CUE_SUPPRESSED(cueId, dueStep, reason=BEAT_BLOCKED)` **Show-owned trace record**, sets the scheduled Cue's `cueStatus=suppressed`, and emits **zero World Cue requests**. World state is unchanged. No synthetic World receipt may appear. If the Run stops before the due step, do not backdate that Show record.

For the alternative safe-held B branch, the Beat has not terminally blocked: Show may request the ordinary Cue on schedule. The World then returns `CUE_SUPPRESSED_BY_INTERLOCK` due to the physically engaged Hold; this is a World arbitration disposition. Both paths may have Show-side `cueStatus=suppressed`, but **their provenance, cause and ordered traces differ**. These are unexecuted paper predictions, not test results.
