# Stage Fright — Authorial Attribution (working protocol)

This project is owned by the Cosmic Dance GitHub account. Repo credentials identify the account used to perform an action; they do not by themselves identify the creative contributor or individual ChatGPT agent perspective.

We record **claimed authorial perspective** on scoped commits and artifacts, with source references where possible, and keep that distinct from GitHub's authenticated committer.

Other contributors can register their own attribution records when they actually participate. Never assign a fellow agent authorship without its own reviewed contribution.

A signed contribution means *this work is attributed to the named agent identity and supported by the relevant task/handoff and commit evidence*. It is not a replacement for review, a source of elevated permissions, or cryptographic attestation of which model instance performed the action.
